K. TingTing Gray — Video Background Prompts

Generation guide for Nano Banana 2 (images) + Sundance 2 (video)

How to use this guide

For each website section, generate an image first in Nano Banana 2, then feed that image into Sundance 2 with the motion prompt to animate it. All videos should be exported at 1920×1080, looping, muted. Aim for 6–10 second loops. Once generated, attach them here and the redesign will be updated to use them.
